CHAPTER 03 / 10

Architecture and data flow

A single self-contained HTML page holds CSS, markup, embedded JSON, and browser-side JavaScript. Plotly renders interactive visualizations. html2canvas captures chart cards and PptxGenJS packages the captures into a widescreen PPTX. No backend, database, model inference endpoint, or training process is included.

D.historical: historical_borrowers.csv (425 borrowers), used for descriptive and relationship charts.

D.models: model_comparison.csv, used for cross-validation accuracy, standard deviation and high-risk recall.

D.test: model_test_results.csv (85 rows), used for held-out confusion matrix and test metrics.

D.new: new_borrower_predictions.csv (10 rows), used for prospective risk probability bars and decision register.

To update source data, replace the appropriate array inside const D= on L31 with new JSON records preserving exact field names and expected numeric types. Simply editing the original CSV files on disk does NOT refresh this HTML; the datasets are embedded snapshots. Recalculate or verify hard-coded footnote counts on L30 and any labels such as “ten new borrowers”.

CHAPTER 05 / 10

KPI calculations and behavior

Historical borrowers = count of F, the selected historical cohort.

Observed high-risk rate = count(F with Credit Risk = High) / count(F).

Held-out test accuracy = count(correct test predictions) / count(D.test); NOT controlled by historical filters.

Prospective high-risk flags = count(D.new Predicted Credit Risk = High) / count(D.new); NOT controlled by historical filters.

All four cards are generated by update() (L31), inserted into #kpis (L30), and centered by CSS on L30. The first two KPI values reflect the active historical tab filters; the latter two use complete test/new datasets. The KPI strip is outside the tab panels, so it is not part of per-tab chart-card PowerPoint capture.

CHAPTER 06 / 10

Filter system and important limitations

definitions (L33–38) specifies the selectable fields for each tab. datasets (L39) maps tabs to source arrays. states (L39) holds selections. getSubset(i) (L41) performs exact-string AND filtering. mountFilters(i) (L42–54) builds selectors and reset buttons. renderTab(i) (L56–79) redraws the current tab. Click handlers (L80–87) activate a panel and resize Plotly charts.

Tab 0/1: purpose, housing, gender, job and marital status filter historical data. The hidden legacy selectors are reset to All on tab redraw. Tab 2: Actual Credit Risk and Predicted Credit Risk filter the confusion matrix and displayed test metrics; model CV comparison remains full-population. Tab 3: borrower fields and predicted class filter chart and table.

CAUTION: the code uses window.__tabFilteredHistorical (L87) and a global active tab. update() draws BOTH historical chart groups even when only one tab is visible; shared KPIs reflect the most recently activated historical cohort. Tab 2 and 3 filters do not update global KPI cards. Consider separating renderPortfolio() and renderRelationships() and giving KPIs an explicit filter scope if enhancing the product.

Export is a collection of chart-card screenshots, NOT editable native PowerPoint charts. It does not export the global KPI strip or page intro. If a tab has more than four chart cards, it receives multiple slides. The titles are based on the names array near L95, not automatically read from each <h2>. Export relies on remote libraries, browser canvas support and network access.

CHAPTER 09 / 10

Safe editing recipes

Rename a tab

Edit its navigation button label in L30; edit its <h2> in L30; edit names array in exportAllTabsToPpt() around L95. Keep data-tab and tab ID unchanged.

Change a KPI

Edit the array in update() on L31; update title, expression and explanatory subtitle together. Verify denominators and empty cohort behavior.

Change a chart title

Change <div class="heading"> near its chart ID on L30; if it is used in an export, the captured card will reflect the new heading.

Change colors

Edit executive light CSS (L17–30) for page components and const C (L31) plus hard-coded chart marker/heatmap colors for Plotly. CSS alone does not recolor all Plotly traces.

Change chart axes or gridlines

Edit draw() (L31). showgrid:false and zeroline:false are applied to both axes; axis-specific customizations are passed through each draw() call.

Add a chart

Add <article class="card"> with unique plot div ID inside desired tab grid on L30; add a draw() call in its render path; verify resizing and PowerPoint slide fit.

Add a filter

Add [field,label] in definitions (L33–38), ensure field exists in matching D dataset, and verify getSubset() comparisons for number/string types.

Update model results

Replace D.models or D.test inside const D (L31); verify model field names and confusion labels; do not claim retraining occurred.

Change PowerPoint page density

Edit perSlide, cols, rows and cell geometry around L107–116; test legibility at normal presentation zoom.

CHAPTER 10 / 10

Validation and maintenance checklist

Back up the original HTML before changes and edit a copy.

Open the edited file in Chrome with internet access; check Developer Tools Console for JavaScript errors.

Check all four tabs, each filter, multi-filter combinations, Reset filters, and empty-result cohorts.

Verify chart and KPI denominators against the supplied CSVs; beware small sample sizes.

Confirm correlation coefficients and risk rates after changing data or feature definitions.

Export PowerPoint after filtering each tab; verify all slide titles, card visibility, readability, and correct selected cohort.

Do not interpret correlations as causal evidence or uncalibrated scores as true default probabilities.

Review protected attributes, fairness, model validation and governance before credit decision deployment.
